行李寄存助手 · 网页演示版（2026-10-03 最新版）

包含功能
服务首页、模拟 AI 对话、预约草稿、报价、预约表单、订单与模拟取件。

本项目是纯静态网页，不需要 npm install、数据库或 API Key。
AI 对话采用本地规则模拟，不会调用真实模型。
预约、支付和取件均为演示；数据只保存在当前页面会话中，刷新即重置。

本地预览
解压后双击 index.html 即可打开。
也可在解压目录运行 python -m http.server 8000，然后访问 http://localhost:8000 。

部署到其他平台
将 index.html、style.css、app.js 一起放在网站根目录。
支持静态网站的托管平台即可，不需要构建命令。
不要只上传 index.html；它还需要同目录中的 CSS 和 JavaScript。

部署到 Vercel
将解压后的全部文件上传到 GitHub 仓库，再在 Vercel 导入该仓库。
Framework Preset 选择 Other；Build Command 留空；Output Directory 使用 . 。
注意本压缩包已把网页文件放在根目录，不需要再填写 dist。

面试演示路径
首页输入“两个24寸箱子，明天10点存，后天18点取”
→ 补充或修改信息 → 生成预约草稿 → 确认并带入预约表单
→ 核对预约与费用 → 提交示例预约 → 模拟门店确认、付款、寄存、取件。
存取时间与营业时间按伦敦当地时间计算。
